# Loopfield — Support

Loopfield is an eight-track sequencer and synthesizer for iPhone and iPad.

## Contact

For help or bug reports, email **daftlamb@gmail.com** with your device model, iOS version and a short description. Please do not send passwords or private files.

## Quick start

Tap Play to hear the current project. Select a numbered track, tap steps to enable notes, and hold/drag a step vertically to adjust pitch. SOUND shapes the voice; SONG arranges patterns; FX controls effects; VISUAL shows reactive scenes. Open **?** for the complete English/Chinese guide and factory projects.

Your edits save on your device. Use the project menu to save a named copy or export a JSON backup. WAV export supports projects using the built-in instruments, within the app's duration limit.

## AUv3 instruments

Install an AUv3 instrument app, then select it under SOUND → INSTRUMENT. OPEN displays its editor. Each track shares its selected instrument across patterns. Keep the plugin app installed to reopen saved projects. Plugin audio currently bypasses Loopfield effects and audio-reactive analysis. WAV export is unavailable for projects containing AUv3 instruments. Loopfield is an instrument host, not an AUv3 plug-in itself.
